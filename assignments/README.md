# Assignments

Homework handouts for EMB_25, as distributed in class.

**Naming:** `EMB_25_HW<NN>_<topic>.pdf` — e.g. `EMB_25_HW03_Timers_PWM.pdf`

PDFs are tracked in git (the shared `.gitignore` deliberately does not exclude
them). Keep them here rather than inside project folders so a handout that
covers several projects only exists once; each project README links back to its
handout with a relative path.
